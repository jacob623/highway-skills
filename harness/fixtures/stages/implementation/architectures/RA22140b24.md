# Scheduled Restock Alert Service

## Current Decisions

- ADR4222f832

Carries: A weekly scheduled job that reads stock levels and sends one alert.

## Context

Applies: When stock needs checking on a fixed schedule without a person starting it.
Leaves Open: The scheduler, the alert channel, and the exact schedule.

## Architecture Summary

A scheduler starts a job each week. The job reads stock levels and reorder points from the order system, selects the items at or below their reorder point, and sends one alert to the warehouse lead.

## Architecture Style

Style: Scheduled batch
Why: The check is periodic and needs no user interaction.

## Logical Components

- Component: Scheduler
  Responsibility: Starts the job each week.
  Interface: None
- Component: Stock reader
  Responsibility: Reads stock levels and reorder points.
  Interface: Read-only stock query
- Component: Alert sender
  Responsibility: Sends one alert listing items to restock.
  Interface: Notification message

## Information

Stock levels and reorder points, owned by the order system. No customer or payment data crosses the job boundary.

## Variation

Must Keep: A weekly schedule, read-only access to stock, and one alert per run.
May Choose: The scheduler, the alert channel, and the run time.

## Responsibilities

- Start the check each week
- Read stock levels without writing them
- Send one alert listing items at or below their reorder point

## Interaction Model

The scheduler starts the job, the job queries stock, and the job sends the alert.

## Trust Boundaries

The job holds a read-only credential for the stock query, kept in a secrets store.

## Deployment Pattern

A scheduled job on a hosted runner.

## Constraints

No new paid vendors (ADR4222f832). Payment data is never read (CTLf124f030).

## Objective Relationships

- OBJ27e16808: advances

## Control Relationships

- CTLf124f030: bound by

## NFR Relationships

- NFRe124ce38: satisfies

## Required Capabilities

- Component: Scheduler
  Capability: Weekly restock alert
- Component: Stock reader
  Capability: Reorder point check

## Assumptions

The order system exposes a read-only stock query.

## Risks

A failed run goes unnoticed without an owner watching the scheduler.

## Reference Implementation Guidance

Use a scheduler the team already runs, and keep the stock credential read-only.
