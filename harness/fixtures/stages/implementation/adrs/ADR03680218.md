## Context

Problem: Northwind Outfitters already builds and deploys with GitHub Actions and needs that recorded as a decision.
Forces: The team runs every repository on GitHub and has no separate build server.
Evidence: None

## Decision

Selected Option: GitHub Actions
Selection Source: Accepted onboarding mapping
Decision Statement: Delivery and scheduled jobs run on GitHub Actions.
Decision Authority: Store manager
Decision Rationale: The team already runs it for every repository.
Authorization: Proceed to Reference Architecture; implementation authorization is excluded.

## Decision Scope

Covers: Where builds, deployments, and scheduled jobs run.
Leaves Open: None

## Revisit When

The team moves repositories off GitHub.

## Decision Confidence

Discovery Confidence: None
Confidence Considerations: Recorded from current practice.

## Alternatives Considered

Definition: A self-hosted build server.
Outcome: Rejected
Reason: The team has no server to run it on.
