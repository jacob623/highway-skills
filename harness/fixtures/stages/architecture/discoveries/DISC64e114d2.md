# Weekly Order Restock Alerts Options

## Request Reference

Request: REQ0464e132

Problem: Popular items sell out before anyone notices, and orders for them wait for stock, which breaks one-day shipping.
Desired Change: Each week, items at or below their reorder point are found automatically and the warehouse lead receives one alert listing them.
Success Measure: No order waits for restock on an item that was below its reorder point on the previous alert.

## Research Findings

The order service already holds stock levels and reorder points. The request prefers GitHub Actions and rules out new paid vendors.

Product Claim Checks:
- Claim: GitHub Actions scheduled workflows
  Source: GitHub Actions documentation on the schedule event
  Result: confirmed

## Assumptions

The order service exposes stock levels through a read-only query.

## Risks

A missed weekly run delays the alert by a week.
