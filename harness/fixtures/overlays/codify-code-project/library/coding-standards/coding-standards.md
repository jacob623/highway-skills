# Coding Standards

The organization maintains this folder. Each standard covers one language or platform, and each row below names one standard file in this folder.

| Standard Title | Technology | File Patterns | Summary | When to use | When not to use | Inherits From | Standard Path |
|---|---|---|---|---|---|---|---|
| Python Coding Standard | Python | `*.py` | How Northwind Outfitters writes Python programs. | programs; scripts | workflow files | | `library/coding-standards/python.md` |
| GitHub Actions Coding Standard | GitHub Actions | `*.yml` | How Northwind Outfitters writes GitHub Actions workflows. | workflows; scheduled jobs | | YAML Coding Standard | `library/coding-standards/github-actions.md` |
| YAML Coding Standard | YAML | `*.yml`, `*.yaml` | How Northwind Outfitters writes YAML files. | configuration | | | `library/coding-standards/yaml.md` |

Adding a standard adds one row and changes no other row.
