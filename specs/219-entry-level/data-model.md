# Data Model: Entry Level

## Class of automation

- Text: one condition or one outcome, five words or fewer, one thing.
- Source: `entry level`, on a platform add or a coding standard add, only when `current` describes it for the type.
- Level: the agent examples (Agentic automation, Local machine execution, Human in the loop, MCP integration, Sensitive data handling, Autonomous automation) and the pipeline examples (Continuous integration, Continuous delivery, File-based triggers, Workflow orchestration).
- Count on an add: one to four per list.
- Not a class: a task, such as Code change proposals, Pull request review, Bug investigation, or Test authoring.

## Proposal entry form

```markdown
1. [Entry]

   **Why it matters:** [One sentence stating the consequence of this entry.]
```

- The sentence names no customer, product, or decision of this organization.
- Saved, viewed, and quoted: the entry alone.

## Saved entry

- Kept on an update, including one the person added.
- Rewritten only when over five words or joining two things. The rewrite is stated in its **Why it matters:** sentence.

## Proposal-wide consequence

- The opening sentence states the consequence of the change.
- It names a rule `standard rules` left out.
- On a standard remove, it says `[Standard Path]` remains and is no longer used.
- Neither proposal has a **Consequences:** section.

## Step order

`current`, `entry level`, `use entries`, `platform proposal`.
