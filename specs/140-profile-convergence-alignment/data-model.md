# Data Model: Profile Convergence Alignment

This feature introduces no persisted fields or schema changes. The entities below describe transient reasoning boundaries already governed by the existing Profile and Experience Standard contracts.

## Profile Domain Candidate

- **Domains:** Identity, Vision, Competitive Path, Guiding Principles.
- **Meaning:** A coherent, supported answer to one Profile domain.
- **Validation:** It must answer the active domain without unsupported facts; completeness alone does not permit final validation.
- **Persistence:** Only after the existing owner-controlled acceptance and mutation path succeeds.

## Profile Working Idea

- **Contents:** Accepted context, active evidence, interpretations, connections, possibilities, alternatives, implications, assumptions, challenges, recommendations, and substantive responses.
- **State:** Transient and subject to contextual re-evaluation.
- **Transition:** A substantive response or newly surfaced relationship can return a domain-complete candidate to collaborative development.

## Converged Proposal

- **Meaning:** A complete Profile Domain Candidate whose Working Idea has also converged under the shared Experience Standard.
- **Transition:** It may proceed to the existing domain-specific accuracy validation question.
- **Persistence:** It is not accepted knowledge until the owner accepts it and the existing mutation succeeds.

## Provisional Profile Structure

- **Forms:** Identity facets, Vision themes, Competitive Path strategic pieces, or Guiding Principles lists.
- **Meaning:** A temporary representation of developed Working Idea substance.
- **Validation:** It must be regenerated or revised when useful discussion changes the underlying meaning; it cannot substitute for collaborative development.
