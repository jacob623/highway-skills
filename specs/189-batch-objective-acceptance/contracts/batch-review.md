# Contract: Batch objective review

## When it appears

Asking to review the selected objectives opens this review. It replaces the one-at-a-time capture. It does not replace the review of objectives already stored.

## Message

**Here's what I've captured as your objectives:**

**[Title]:** [One sentence]

**Success looks like:**
- [Success measure]

**Why it matters:** [Rationale]

---

The rule appears between objectives only. Each objective has at least one success measure. A second measure is included when the accepted profile supports it.

**What would you add, correct, or remove?**

If this is accurate, just say so.

## Replies

| Reply | Result |
|---|---|
| Accurate, including "looks good" | Store every objective still in the set. Show no stored record and no closing line. |
| Add, correct, or remove | Show the whole revised set again. Store nothing yet. |
| Question or unclear | Show the same set again. |
| Decline the set | Store none of that set. |

The removed lines are:

- **Here's what I've captured as your objective:**
- Your accepted Objectives now cover [short phrases for the held Objectives].
- Next we'll develop **[next title]**.

## Stored text

| Record section | Review text |
|---|---|
| Statement | The one sentence beside the title |
| Success Measures | The measures under **Success looks like:** |
| Rationale | The line beside **Why it matters:** |
