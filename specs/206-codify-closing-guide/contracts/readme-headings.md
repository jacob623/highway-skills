# Contract: README Headings

Applies to the README task in `highway-codify` `code` and the Readme block in `codify-record.md`.

```markdown
## Setup Instructions

<what is put in place, where it goes, and how to enable it, including preparation>

## User Guide

<how a non-technical person starts this one automation, what they provide, and what comes back>
```

- The two headings appear in this order and are the only `##` headings.
- `## Implement` and `## Use` do not appear in the skill or the template.
- Setup Instructions is for the person who accepted the proposal. User Guide follows the interface of the Provider and does not ask the reader to edit generated files or read the implementation record.
