# Data Model: Constitution Collaborative Knowledge Cleanup

This feature has no new persisted data model. It preserves and reorders existing governance concepts.

## Governance entities

- **Repository Context**: Accepted context that constrains context-dependent behavior and ranks 11 in Principle Precedence.
- **Owner-Controlled Completion**: Principle XII and P12.5-P12.15, including the acceptance-to-owner-result persistence boundary.
- **Collaborative Knowledge Development**: Principle XIII, physically located after the persistence boundary while retaining P12A.1-P12A.4 identifiers.
- **Active Reasoning Context**: Existing transient context defined by the Constitution; unchanged by this cleanup.
- **Working Idea**: Existing non-authoritative evolving idea; unchanged by this cleanup.
- **Converged Proposal**: Existing complete candidate concept; unchanged by this cleanup.
- **Accepted User-Owned Artifact**: Existing owner-mutated artifact concept; unchanged by this cleanup.

## Ordering and authority relationships

```text
XI. Repository Context
  -> XII. Owner-Controlled Completion and Orchestration
  -> Acceptance-to-owner-result persistence boundary
  -> XIII. Collaborative Knowledge Development
  -> Principle Precedence

Accepted Repository Knowledge
  -> constrains Active Reasoning Context
  -> Working Ideas evolve collaboratively
  -> complete candidate becomes a Converged Proposal
  -> acceptance authorizes owner mutation
  -> persisted knowledge becomes authoritative
  -> later reasoning re-evaluates relevant context
```

The cleanup changes section placement and precedence metadata only. It creates no new entity,
retained artifact, or persistence path.
