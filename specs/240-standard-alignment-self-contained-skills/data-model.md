# Data Model: Standard Alignment Self-Contained Skills

## Help index (`skills/highway-help/assets/index.json`)

Generated by `framework/generate-catalog.sh`; never edited by hand.

| Field | Type | Source |
| --- | --- | --- |
| `entries` | array of entries | one per `skills/<folder>/SKILL.md`, folder order (`LC_ALL=C`) |
| `id` | string | the folder name, equal to `name` (FR-002) |
| `name` | string | frontmatter `name` |
| `description` | string | frontmatter `description` |
| `usage` | string | `/<name>` |
| `version` | string | `metadata.version` |
| `dependencies` | array of string | `metadata.dependencies`, each `<path>@<version>`; `[]` when absent |
| `example` | string | the first line under `## Example` that is one inline code span, without the backticks; `""` when absent |

Invariant: the file is byte-stable across regenerations. highway-help's agent copies carry
the same bytes.

## Bundled file

A file in a skill's `references/`, `assets/`, or `scripts/`.

| Kind | Where | Checked by `validate-skill.sh` |
| --- | --- | --- |
| Complete template | `assets/*.md` not seeded and not a Mode B skeleton | frontmatter `name`, `description`; constitution rules minus template-exempt and bundled-exempt ids |
| Seeded skeleton | `assets/*.md` named in highway-setup's Seed table | not judged as a template (catalog seeding test compares it) |
| Reference | `references/*.md` | constitution rules minus bundled-exempt ids and P7.2 |
| Generated asset | `highway-help/assets/index.json` | not `.md`; covered by the generator and drift checks |

Path rule: named in `SKILL.md` as `<folder>/<file>`, one level deep, and the file exists.

## Distribution record

`.distribution-record` at the distribution root, previously `.highway/.distribution-record`. Same
format: `<relative path>\t<sha256>` per generated file.

## Harness base

`<work>/base/.github/skills/<name>/`, a copy of each `skills/<name>/` that has a `SKILL.md`. It is
built once per run. Every scenario project is the base plus the fixture, and a chain snapshot
leaves the base's paths out.
