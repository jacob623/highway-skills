# Contract: Highway capability line

## Capability list

The starting point includes this line with the other capabilities:

**Highway:** Connect accepted business goals, decisions, architecture, and implementation work into a single traceable system of knowledge.

The person may correct or remove it before accepting the list. A removed line is not mapped.

## Mapping

| Condition | Provider |
|---|---|
| The session identifies the agent platform by name | That name |
| The session does not identify a name | The existing prompt that asks the person to name the platform |
| The person corrects the name | The corrected name |

Other capabilities keep their own providers. Onboarding does not authorize the agent platform to act on its own.

## Duplicate

When an accepted decision already records Highway for the same provider name, the capability list omits the new Highway line.

## After acceptance

Highway follows the existing provider path: one decision, one reference architecture, and one reference implementation.
