# Data Model: Objectives Skill Rename

## Canonical Skill Identity

- **Identifier**: `highway-objectives`.
- **Source**: `.highway/skills/highway-objectives/SKILL.md`.
- **Command**: `/highway-objectives`.
- **Adapters**: `.github/skills/highway-objectives/SKILL.md`, `.claude/skills/highway-objectives/SKILL.md`, and `.cursor/rules/highway-objectives.mdc`.
- **Catalog identity**: `highway-objectives` in `.highway/catalog/index.json` and `index.md`.
- **Manifest identity**: plural paths in `.highway/tools/.adapter-manifest` and `.highway/tools/.distribution-manifest`.

## Legacy Artifact Set

The following singular artifacts must be absent after migration:

- `.highway/skills/highway-objective/`
- `.github/skills/highway-objective/`
- `.claude/skills/highway-objective/`
- `.cursor/rules/highway-objective.mdc`
- Singular adapter-manifest and distribution-manifest rows
- Singular catalog entries, source paths, command examples, tests, fixtures, and tracked documentation references

## Generated Artifact Relationships

- Source skill frontmatter and directory name determine catalog identity and adapter content.
- Catalog entries reference the plural source path and frontmatter values.
- Adapter manifest rows record generated plural adapter paths, skill identity, version, and hashes.
- Distribution manifest rows classify plural source, template, and adapter paths for packaging.
- Regeneration must produce no singular artifacts or rows.

## Ownership Boundary

- `.highway/` source, templates, catalogs, manifests, and generated adapters are framework-owned and
  may be renamed or regenerated by this feature.
- Root-level `library/objectives/` and `library/governance/objectives.md` are user-owned and are
  excluded from migration writes and distribution generation.
- Feature 027 remains a separate development record; only stale identity references inside it are
  eligible for cleanup.

## Migration Invariants

1. Exactly one canonical skill identity exists: `highway-objectives`.
2. No exact singular legacy token remains in tracked active or historical repository content.
3. No singular source, adapter, catalog, manifest, test, fixture, or documentation path remains.
4. Every plural generated artifact resolves to the plural source skill and has current hashes.
5. The distribution contains plural source and adapters only.
6. Root-level user-owned objective bytes are unchanged or remain absent.
7. Feature numbering and the Feature 027 directory are unchanged.
