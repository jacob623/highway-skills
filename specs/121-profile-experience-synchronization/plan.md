# Implementation Plan: Experience Conversational Presence

**Branch**: `121-profile-experience-synchronization` | **Date**: 2026-10-01 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/121-profile-experience-synchronization/spec.md`

## Summary

Amend only the Highway Experience Standard to make Conversational Presence explicit as non-normative guidance distinct from Conversational Voice and Constructive Advisory. The implementation will correct the Conversational Voice heading hierarchy, add Presence guidance and examples, clarify that one-question limits do not require a question on every turn, broaden advisory value beyond decision-only value, preserve all named normative rules and Observables, and update the applicable MINOR version metadata and directly affected checks.
