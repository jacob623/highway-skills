# Contract: Profile conversation and file

## Conversation

Vision, Competitive Path, and Guiding Principles each emit a proposal and **What would you add, correct, or remove?** They do not emit:

- **What is the future vision of [Name]?**
- **How does [Name] plan to get there?**
- **What principles or values guide decisions at [Name]?**

They do not emit **Here's what I've captured as your [domain]:**.

Identity may still emit **What does [Name] do?** when no supported starting point exists. That answer is held as Identity bullets without a capture paragraph.

## File

| Item | Value |
|---|---|
| Path | `library/knowledge/profile.md` from the repository root |
| Template | `.highway/library/templates/output/profile-record.md` |
| Domain content | Accepted bullets under the domain heading |
| Write count | One, after Guiding Principles is accepted or declined |

The template narrative slots say the section is the accepted bullets. The old path `.highway/library/knowledge/profile.md` is not a profile source.
