# Data Model: Interpretation Confidence

This feature introduces no persisted data entities or schema changes. The following behavioral
entities are documented to map the specification to validation and implementation tasks.

## Grounded Interpretation

- **Meaning**: A provisional distinction, implication, connection, tension, structure, organizing principle, or Working Idea supported by accepted evidence.
- **Lifecycle**: Offered as a Working Idea, remains attributable and provisional, and may influence later development only under existing Profile and Experience Standard rules.
- **Validation**: Must be traceable to accepted evidence and must not be a repetition, unsupported claim, material guess, or detached strategic leap.

## Consequential Uncertainty

- **Meaning**: Unresolved information owned by the person that can materially change the result and cannot be resolved by accepted evidence or responsible advisory reasoning.
- **Lifecycle**: Remains unresolved until the existing focused clarification behavior obtains the needed information.
- **Validation**: Interpretation confidence must not suppress the clarification required for this uncertainty.

## Interpretation Confidence

- **Meaning**: A Profile selection rule that prefers a grounded interpretation over an unnecessary question seeking permission to express it.
- **Relationship**: It selects between existing interaction moves; it is not a contribution type, acceptance boundary, stored state, or new owner contract.

## Generated Adapter Set

- **Meaning**: The Profile skill copies distributed to `.github/skills`, `.claude/skills`, `.cursor/skills`, and `.agents/skills`.
- **Relationship**: Each adapter must correspond to the authoritative `.highway/skills/highway-profile/SKILL.md` source after regeneration.
