# Contract: Conflicts

```markdown
1. **[Conflict]:** [Description quoting both entries and naming both records]. Recommendation: [Change].

**Which conflict would you like to resolve?**

If you'd like to cancel, just say so.
```

No conflicts: "Highway found no conflicts." then "**What inconsistencies have you noticed?**" Then reassess.

Resolution:

```markdown
1. **[Standard Title or Platform]**
   a. [Change]
   b. [Change]

**What would you add or correct?**

If you'd like to cancel, just say so.
```

`accept` writes only those changes, then reassesses and re-emits the list.
