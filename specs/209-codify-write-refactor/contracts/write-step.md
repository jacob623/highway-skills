# Contract: Write Step

`write` contains, in order:

1. The opening paragraph: write `code/[ID]/codify.md`, `code/[ID]/codify-tasks.md`, and `code/code.md` together; none until all are valid; nothing partial; no README or task-list file here.
2. The record sentence and its bullets.
3. `The task list follows `.highway/library/templates/output/codify-tasks.md`.`
4. The catalog sentence and its bullets.
5. `On success, go to `code` without asking a question.`

`write` does not contain:

- `[Executor]`
- `Tests: required`
- `The README task is last.`
- `Each proposal task is one feature`
- `Each line names its files`

`write` is at most 250 words, excluding its heading.
