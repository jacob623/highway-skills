# Phase 1 Data Model: Skill Id Namespace Alignment

## Entities

### Canonical Skill Directory

The single directory under `.highway/skills/` that is the source of truth for a skill's content.

| Attribute | Before this feature | After this feature |
|---|---|---|
| Directory name | Bare, unprefixed id (e.g. `help`) | Full agent-facing id (e.g. `highway-help`) |
| Relationship to catalog `id` | `id` = directory basename, unprefixed | `id` = directory basename, already fully namespaced |
| Relationship to generated adapter path basename | Adapter basename = `highway-<id>` (computed by the generator's template) | Adapter basename = `<id>` (the id, unchanged by the generator — already fully namespaced) |

**Validation rule**: directory name MUST match `^[a-z0-9]+(-[a-z0-9]+)*$` (`sv_validate_id`,
unchanged regex — a fully-namespaced id such as `highway-help` already satisfies kebab-case with
no new character-set rule needed).

### Skill Frontmatter Name

The `name` field inside a skill's `SKILL.md` frontmatter.

| Attribute | Before this feature | After this feature |
|---|---|---|
| Value for `help` | `Help` (free-form display label) | `highway-help` (byte-identical to the directory-derived id) |
| Validation | None — `_authoring-standard.md` stated `name` is "free-form ... never required to match" | MUST equal the directory-derived id exactly; enforced by new `sv_validate_name` |
| Consumed by help output's `Name:` field? | No (specs/008 deliberately computed `Name:` as `highway-<id>`, never trusting frontmatter `name`) | Yes, indirectly: `Name:` continues to be computed from the catalog `id` (now already the full form, so no concatenation needed) — reading `id` and reading a validated-equal `name` now always agree |

**Validation rule** (new): `name` (frontmatter) MUST equal `id` (directory basename) exactly,
byte-for-byte. Violation message shape: `ERROR: [SCHEMA] frontmatter 'name' ('<name>') does not
match directory-derived id '<id>'`.

### Agent Adapter Target Template

The per-agent path-construction rule in `generate-agent-adapters.sh` (`AGENT_TARGET_TEMPLATES`).

| Attribute | Before this feature | After this feature |
|---|---|---|
| github-copilot | `.github/skills/highway-%s/SKILL.md` | `.github/skills/%s/SKILL.md` |
| claude-code | `.claude/skills/highway-%s/SKILL.md` | `.claude/skills/%s/SKILL.md` |
| cursor | `.cursor/rules/highway-%s.mdc` | `.cursor/rules/%s.mdc` |
| Resolved path for `help`/`highway-help` | `.github/skills/highway-help/SKILL.md` (id=`help` substituted into `highway-%s`) | `.github/skills/highway-help/SKILL.md` (id=`highway-help` substituted into `%s`) — **byte-identical result** |

**Retired**: `AGENT_OLD_TARGET_TEMPLATES` and its associated `check_stale_removable` /
`remove_stale_target` functions (research.md R3) — no longer called from any code path.
