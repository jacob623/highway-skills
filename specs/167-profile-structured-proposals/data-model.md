# Data Model: Profile Structured Proposals

This feature introduces no persisted data model. The following conceptual entities describe
transient working interpretations and existing accepted Profile context that the skill must
preserve.

## Vision Starting Point

- **Purpose**: A transient, structured interpretation of accepted Profile evidence offered for the
  person's reaction before Vision convergence.
- **Content**: Domain-appropriate structured bullets revealing major Vision elements.
- **Persistence**: None until the existing Vision proposal is accepted through the existing boundary.
- **Ownership**: Profile interaction guidance; not accepted organizational knowledge.

## Competitive Path Starting Point

- **Purpose**: A transient, structured interpretation of how the organization may advance toward its
  accepted or developing Vision.
- **Content**: Domain-appropriate structured bullets showing the approach, advantage, tradeoffs, or
  other meaningful path elements supported by accepted context.
- **Persistence**: None until the existing Competitive Path proposal is accepted.
- **Ownership**: Profile interaction guidance; not an accepted strategy or plan.

## Guiding Principles Starting Point

- **Purpose**: A transient set of individually visible potential decision-making values derived from
  accepted Profile evidence.
- **Content**: Separate structured principle items that can be added, corrected, removed, or
  replaced independently.
- **Persistence**: None until the existing Guiding Principles proposal is accepted.
- **Ownership**: Profile interaction guidance; not Controls, accepted principles, or organizational
  facts.

## Contribution Opportunity

- **Purpose**: An invitation to add, correct, remove, redirect, or replace substance before
  convergence.
- **State**: Working Idea only; not a candidate, Converged Proposal, or acceptance request.
- **Transition**: Starting point -> person reaction -> re-evaluation and refinement -> existing
  domain convergence -> existing domain proposal -> existing acceptance boundary.
- **Fallback**: If accepted evidence cannot support a responsible starting point, the workflow uses
  the existing focused-question path.

## Accepted Profile Context

- **Purpose**: User-owned accepted Identity, Vision, Competitive Path, Guiding Principles, and other
  Profile evidence available to ground later domain interpretation.
- **Authority**: Accepted context remains authoritative; Highway's starting point remains provisional
  until the existing owner-controlled acceptance boundary is crossed.
- **Persistence**: Existing Profile persistence behavior is unchanged.

## State and Persistence Constraints

- No new Profile field, identifier, lifecycle state, readiness dimension, or retained artifact is
  added.
- A person's correction or redirection changes the working interpretation before convergence; it does
  not silently accept the starting point.
- A request for explanation or comparison is not acceptance.
- Existing attribution, ownership, convergence, persistence, and readiness rules remain authoritative.
