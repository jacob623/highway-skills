# Contract: Guided Flow Copy

## Profile starting points

Vision:

```markdown
- **Future Direction**

  [Inferred from accepted context.]

- **Desired Impact**

  [Inferred from accepted context.]

- **Future State**

  [Inferred from accepted context.]
```

Competitive Path uses the same form for **Primary Approach**, **Strategic Advantage**, and **Important Tradeoff**.

Guiding Principles:

```markdown
- **[Short principle name]**

  [Accepted-evidence decision-making value.]
```

## Recommendation item

Objectives, Controls, and NFRs:

```markdown
1. **[Title]:** [One sentence.]
```

Number every recommendation in the set, starting at 1.

## Closing copy

First set, and the set shown with the queue:

| Skill | Copy |
|---|---|
| Objectives | **Which of these outcomes would you like to pursue, or what would you like to focus on?** / You can select some, all or provide your own outcome. / If you'd like additional suggestions, just say so. |
| Controls | **Which of these safeguards would you like to establish, or what would you like to focus on?** / You can select some, all or provide your own safeguards. / If you'd like additional suggestions, just say so. |
| NFRs | **Which of these operational expectations would you like to establish, or what would you like to focus on?** / You can select some, all or provide your own operational expectation. / If you'd like additional suggestions, just say so. |

Each `/` is a paragraph break.

Set shown when the queue already has items: that set's existing question, unchanged and first, then the same two lines for that skill.

## Exhaustion follow line

| Skill | After | Add |
|---|---|---|
| Objectives | **Are you ready to review the selected objectives?** | If you'd like to add another outcome first, just say so. |
| Controls | **Are you ready to review the selected Controls?** | If you'd like to add another safeguard first, just say so. |
| NFRs | **Are you ready to review the selected NFRs?** | If you'd like to add another operational expectation first, just say so. |

This applies in `more` and in the queue's exhaustion message.

## Removed copy

- "If none of these fit, feel free to suggest your own …"
- "If you'd like additional suggestions, just let me know."
- `- **[Title]:** [One sentence.]` as a recommendation item

## NFR rules

- While an accepted Control is not reflected by a queued, shown, or captured NFR, a set contains only Control-derived recommendations, plus **No system hosting** and **Direct purchase** in the first set.
- Accepted Profile and Objectives refine scope, priority, and wording.
- One NFR may reflect more than one Control.
- After every accepted Control is reflected, a set may include expectations grounded in the accepted Profile or Objectives, or in an uncovered area that would reasonably benefit the organization.
- An unreflected Control is a remaining grounded recommendation.
