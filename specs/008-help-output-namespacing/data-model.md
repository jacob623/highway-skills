# Phase 1 Data Model: Help Output Namespacing

This feature has no database and adds no new entity type. It changes the derivation and
generated-path shape of two existing entities already defined by prior features.

## Namespaced Skill Identifier (redefines specs/007's entity)

| Field | Type | Notes |
|---|---|---|
| `id` | string | Unchanged. The skill's directory-derived id under `.highway/skills/` (e.g. `help`). Source of truth, per specs/001/007. |
| `namespaced_id` | string, computed | `highway-<id>` (hyphen separator). **Changed** from specs/007's `highway.<id>` (dot separator). Computed, never authored, never stored as its own catalog column. |

- Used as: every agent adapter's generated directory/file path segment (github-copilot,
  claude-code, cursor); the help skill's `Name:` field (single-skill and all-skills modes,
  research.md R2); the invocation token inside `Usage:` and `Help:` (research.md R3, R4).
- Validation: unchanged from specs/007 — `id` MUST already satisfy
  `.highway/tools/lib/schema-validate.sh`'s `SV_ID_REGEX='^[a-z0-9]+(-[a-z0-9]+)*$'`; no new
  validation is added because `highway-<id>` is a deterministic concatenation, never independently
  authored or validated.

## Help Output (redefines specs/006's entity)

| Field | Mode(s) | Source (before this feature) | Source (after this feature) |
|---|---|---|---|
| `Name:` | Single-skill, All-skills | Target skill's frontmatter `name` (free-form, e.g. `Help`) | Computed `namespaced_id` (e.g. `highway-help`) — **changed**, research.md R2 |
| `Description:` | Single-skill | Target skill's frontmatter `description` | Unchanged |
| `Dependencies:` | Single-skill | Target skill's `metadata.dependencies` | Unchanged |
| `Version:` | Single-skill | Target skill's `metadata.version` | Unchanged |
| `Usage:` | Single-skill, All-skills | Target skill's frontmatter `usage` (authored prose) | Unchanged mechanism; authored text corrected to reference `namespaced_id` (research.md R3) |
| `Example:` | Single-skill | Target skill's `## Example` section, rendered as prose | Same section, its invocation line now authored as an inline code span (research.md R5) |
| `Help:` | All-skills (per entry) | Computed `/help <id>` | Computed `/highway-help <id>` — **changed**, research.md R4 |

- Mode resolution, error shapes (`ERROR: no skill registered...`, `No skills are registered yet.`),
  and field order are unchanged from specs/006's contract — carried forward, re-stated in this
  feature's superseding contract for a single authoritative reference (matching specs/007's own
  precedent for superseding specs/001's contract).

## State / lifecycle

Neither entity has a lifecycle beyond "generated" (Namespaced Skill Identifier's adapter paths,
regenerated by `generate-agent-adapters.sh`) or "rendered on request" (Help Output, constructed
fresh each time a coding agent processes a `/highway-help` invocation). No persistence, no
transitions.
