# Contract: Experience Profile Presentation

## Global narration boundary

The Experience Standard owns X2.36. Interactive Workflow commentary focuses on the person's information, meaning, choices, implications, or outcome. It does not announce persistence, retained state, unresolved workflow parts, evaluation, routing, or progression unless the person needs that information to act.

## Profile subject rhythm

For each synthesized domain, Profile emits:

1. The prescribed plain-language subject heading.
2. A natural introduction to what the subject means for the organization.
3. One cohesive recommendation grounded only in accepted evidence.
4. The existing domain validation question and user-authored alternative.

After acceptance, Profile acknowledges what the accepted information establishes when X2.8 applies, then repeats the rhythm for the next grounded subject. A final Guiding Principles acceptance uses the existing completion synthesis and does not emit another subject heading or question.

## Preservation contract

- Presentation prose and headings are transient.
- Acceptance, correction/replacement, explanation-not-acceptance, readiness, save-before-result ordering, canonical fallback, and completion ownership remain unchanged.
- The shared Profile record remains schema 3.0.0.
- Profile cites X2.36; it does not create a duplicate generic narration rule.
