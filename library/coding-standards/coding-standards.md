# Coding Standards

The organization maintains this folder. Each standard covers one technology, and each row below names one standard file in this folder.

| Standard Title | Technology | File Patterns | Summary | Standard Path |
|---|---|---|---|---|
| Terraform Coding Standard | Terraform | `*.tf`, `*.tfvars` | How Terraform configuration is formatted, named, versioned, and tested. | `library/coding-standards/terraform.md` |

A file uses the first row whose file pattern matches its name. Adding a standard adds one row and changes no other row.
