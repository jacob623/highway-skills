# Coding Standards

The organization maintains this folder. Each standard covers one language or platform, and each row below names one standard file in this folder.

| Standard Title | Technology | File Patterns | Summary | When to use | When not to use | Inherits From | Standard Path |
|---|---|---|---|---|---|---|---|
| Terraform Coding Standard | Terraform | `*.tf`, `*.tfvars` | How Terraform configuration is formatted, named, versioned, and tested. | Provisioning or changing cloud infrastructure declared as Terraform configuration; Writing Terraform modules, variables, or outputs | Configuring an application inside a running server; Writing Kubernetes manifests or Helm charts | | `library/coding-standards/terraform.md` |

Adding a standard adds one row and changes no other row.
